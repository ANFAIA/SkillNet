# ANFAIA presentation snapshot — prepared 2026-08-31 for 2026-09-01

This document records the product story and implementation boundary presented at the end of the
ANFAIA work period. It is a snapshot, not a claim that every research direction is production-ready.

## Product story at this snapshot

SkillNet began with a concrete training problem: in small and medium organizations, knowledge often
depends on experienced people repeating the same explanations while their regular work waits. The
product creates another channel for that knowledge:

```text
idea or existing source
        → grounded course
        → tutor, activities and learning media
        → attempts, progress and recorded skills
```

The product then asks a second question: if people do not learn from the same explanation in the
same way, why must a shared source always become one fixed experience?

SkillNet separates the shared knowledge and objective from the experience served to a learner
profile and state. Validated dynamic courses can vary explanation, example, activity, medium or
interface while retaining grounding and an evidence bar; equivalent inputs may share a render.

## What the repository implements

- Course creation from an idea and from supported documents.
- Static and dynamic delivery selected per course.
- Course-specific tutor and contextual explain flows that retrieve sources and return provenance;
  general tutor questions may use general mode without course citations.
- OpenUI programs rendered through a supported, version-pinned subset of Didact.
- Didact learning components and evaluated activities.
- Podcasts, infographics, slide decks and narrated slide videos when the required providers are configured.
- Enrollments, attempts, progress, mastery, skills and admin talent surfaces.
- External REST API plus optional A2A and MCP adapters enabled through Compose profiles.
- Organization and individual workspace setup.
- Self-hosted Docker deployment with provider-agnostic model configuration.

## What remains validation or future direction

- Demonstrating that a chosen adaptation improves learning rather than merely changing the screen.
- Surfacing the implemented inspect, edit and clear memory controls in the learner product, and
  extending memory beyond tutor personalization into evaluated lesson experiences.
- Synchronizing affected training when source knowledge changes.
- Expanding multimodal source ingestion and improving generated media quality.
- Using open-ended generated interfaces only where a controlled component catalog cannot express the
  learning task and reliability justifies the cost.
- Proactive agents that accompany longer learning journeys under explicit user control.

## Product principles carried forward

1. Grounding before generation.
2. The same knowledge can support a different path.
3. Immediate intent and accumulated memory are different inputs.
4. Personalization is a revisable hypothesis, not a label.
5. Components are part of the pedagogy, not decoration.
6. Completion, mastery and skill are separate, traceable claims.
7. Controlled interface generation is the practical default.
8. SkillNet remains open, self-hosted and interoperable.
