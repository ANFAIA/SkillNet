# Roadmap

> Updated: 2026-08-31. This roadmap is intentionally short. The current product and its boundaries
> are documented in [Product](design/product.md) and [Vision](design/vision.md).

## 1. Improve course quality

- Improve the accuracy, grounding and educational quality of structures, lessons and activities.
- Evaluate changes with repeatable benchmarks and real company documents.

## 2. Fine-tune models for course generation

- Build reviewed datasets and evaluate fine-tuning and LoRA for course generation.
- Compare specialized and general models on quality, latency and cost before adopting them.

## 3. Explore new learning interfaces

- Explore Generative UI, Didact, Curio and other ways to explain, practise and interact.
- Keep controlled components as the reliable baseline and test whether new interfaces improve learning.

## 4. Fix errors and improve reliability

- Fix bugs and make the complete `source → course → learner → progress` journey dependable.
- Improve validation, fallbacks, tests, error messages and self-hosted setup.

## Principle

Ship fewer directions, test them properly and keep what demonstrably improves the product.
