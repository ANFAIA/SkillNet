# Investigación

Investigaciones realizadas como parte del desarrollo de SkillNet. Cada tema incluye el contexto, qué se exploró, qué se descubrió y hacia dónde va la investigación.

| Tema | Qué explora | Estado actual |
|-------|-----------------|----------------|
| [Fronteras Semánticas](/docs/semantic-boundaries) | ¿Puede una IA determinar quién debería acceder a qué información solo a partir del contenido? | Se concluyó que la privacidad es una decisión humana, no una propiedad del contenido. Explorando control de acceso estructural. |
| [Generative UI](/docs/generative-ui-research) | Cómo los agentes de IA pueden generar interfaces de usuario, y cómo hacerlo práctico a escala | Se construyó A2TL-Web (Nivel 2). Explorando el Nivel 3 y cómo gestionar la latencia de generación. |
| [Coordinación Multi-Agente](/docs/multi-agent-coordination) | Cómo coexisten equipos de humanos y agentes en proyectos compartidos | Se exploraron estructuras organizativas. Se descubrió el modelo de autoridad basado en mandatos. Se construyó [DBP](https://github.com/JoseEstevez520/DBP) como protocolo determinista de fronteras de datos. |
| [Post-Markdown](/docs/post-markdown) | Qué viene después de Markdown como formato de contexto para agentes de IA | Se construyó mcp-md-reader para consumo optimizado. La evolución del formato sigue abierta. |
| [Aceleración de inferencia](/docs/inference-acceleration) | Cuánto puede acelerar la generación el hardware de inferencia especializado, y qué haría falta para llevarlo a producción | Se midieron Groq y Cerebras; Groq es un proveedor de modelos admitido. Las ramas de LoRA, router y "páginas vivas" se exploraron y no se adoptaron. |
