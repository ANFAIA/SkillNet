# Research

Investigations conducted as part of SkillNet's development. Each topic includes the context, what was explored, what was discovered, and where the research is heading.

| Topic | What it explores | Current status |
|-------|-----------------|----------------|
| [Semantic Boundaries](semantic-boundaries/) | Can AI determine who should access what information from content alone? | Concluded that privacy is a human decision, not a content property. Exploring structural access control. |
| [Generative UI](generative-ui/) | How AI agents can generate user interfaces, and how to make it practical at scale | Built A2TL-Web (Level 2). Exploring Level 3 and how to handle generation latency. |
| [Multi-Agent Coordination](multi-agent-coordination/) | How teams of humans and agents coexist on shared projects | Explored organizational structures. Discovered mandate-based authority model. Built [DBP](https://github.com/JoseEstevez520/DBP) as deterministic data boundary protocol. |
| [Post-Markdown](post-markdown/) | What comes after Markdown as a context format for AI agents | Built mcp-md-reader for optimized consumption. Format evolution remains open. |
