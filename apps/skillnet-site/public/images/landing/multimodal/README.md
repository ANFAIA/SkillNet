# Landing multimodal illustrations

The generated illustrations in this directory were created specifically for SkillNet:

- `learning-differences-infographic-es-v4.webp`: complete Spanish infographic in the minimal information-design direction, including its own title, labels, connections and conclusion.
- `learning-differences-infographic-en-v4.webp`: English-localized version of the same complete infographic.
- `learning-differences-video-storyboard-v4.webp`: a four-frame 2x2 motion-infographic storyboard used by the narrated sequence. Its four frames show four people sharing a course, a person drawing an explanation, a person listening to it, and different routes converging on the same goal.

All assets use white, near-black, cobalt blue and a restrained green success accent. The infographic is selected by locale; the storyboard contains no embedded text because its captions are synchronized with narration.
